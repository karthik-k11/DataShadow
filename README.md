# DataShadow

**Analyze privacy risks. Generate synthetic alternatives.**

DataShadow is a lightweight, local application for analyzing potential privacy risks in structured datasets, generating synthetic alternatives, and comparing statistical utility.

## Planned Features

- CSV dataset profiling
- Potential personally identifiable information (PII) detection
- Privacy-risk warnings
- Synthetic-data generation
- Statistical utility comparison
- CSV export
- SQLite analysis history
- Automated tests

## Technology Stack

- Python
- Flask
- Pandas and NumPy
- HTML, CSS and JavaScript
- SQLite
- pytest

## Development Phases

1. Basic — Core analysis and synthetic-data workflow
2. Intermediate — Improved metrics and privacy-utility controls
3. Advanced — Privacy-risk simulations and advanced techniques

## Privacy Notice

Privacy findings are heuristic warnings, not guarantees of anonymity. Synthetic data can retain privacy risks, and statistical similarity does not establish that a dataset is safe to share.
